# 移动爱家网页版

## 📋 项目概述

这是移动爱家App的网页版实现，目前使用**静态数据模式**，展示从真实设备抓包获取的数据。

## 🎯 当前状态

**✅ 已完成**：
- 完整的网页界面（登录、设备列表、视频播放页面）
- 真实设备数据展示
- 从抓包数据提取的设备信息
- 设备缩略图加载
- 设备详细信息展示

**⚠️ 已知限制**：
- 视频流无法播放（API有加密保护）
- Token会过期，需要重新抓包更新
- 仅支持单个设备展示（当前账号只有一个摄像头）

## 🔧 技术细节

### 核心API域名
```
base.hjq.komect.com       - 基础接口
video.hjq.komect.com      - 视频接口  
esd-media.camera.komect.com - 设备列表
```

### 安全机制
1. **SSL Pinning** - 启用抓包时App会检测证书，导致无法登录
2. **API签名加密** - 所有请求都需要特殊签名算法
3. **Token认证** - 需要有效的用户Token才能访问API

## 🚀 使用方法

### 快速预览
直接打开 `index.html` 即可查看页面效果

### 本地服务器运行
```bash
# Python 3
python3 -m http.server 8000

# Node.js
npx http-server
```

然后访问 `http://localhost:8000`

## 🎨 设计说明

界面采用深色主题，使用流体排版（clamp()）和CSS Grid布局，响应式设计支持移动端和桌面端。

配色方案：
- 主色：青蓝色 (#38BDF8)
- 背景：深灰到黑的渐层 (#05070C → #161D2B)
- 强调色：翠绿 (#6EE7B7) / 暖橙 (#E9A568)

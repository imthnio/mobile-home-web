# 📹 移动爱家网页版

> 将中国移动「移动爱家」App 的监控功能搬到网页上，随时随地浏览器查看。

## ⚡ 快速开始

```bash
cd ~/Desktop/mobile_home_web
./start.sh
```

选择「1」开始抓包，让登录功能可用。

## 🎯 使用流程

### 第一步：抓包获取 API

```bash
./start.sh
# 选择 1) 抓取 API
```

按照屏幕提示：
1. 在 iPhone 上配置代理（3分钟）
2. 打开移动爱家 App 登录
3. 查看抓到的请求
4. 把结果截图或告诉我

### 第二步：更新代码

收到抓包结果后，我会：
- 分析真实的 API 接口
- 更新 `app.js` 中的登录逻辑
- 让功能完全可用

### 第三步：部署到 VPS

```bash
# 上传到 VPS
scp -r mobile_home_web root@你的VPS_IP:/root/

# SSH 登录 VPS
ssh root@你的VPS_IP

# 运行安装脚本
cd /root/mobile_home_web
./install.sh
```

完成！浏览器访问：`http://你的VPS_IP:5000`

## 🤔 为什么要抓包？

移动爱家的 API 没有公开文档，我们需要知道：

1. **登录接口的真实地址** - 虽然找到了服务器，但不知道具体路径
2. **请求参数格式** - 需要哪些字段，参数名是什么
3. **密码加密方式** - 可能是 MD5、SHA256 或其他方式
4. **认证令牌格式** - Token 在哪个 Header 里，格式是什么
5. **视频流地址** - 如何获取摄像头的视频流

只需要抓一次包，就能让整个网页版完美工作！

## 📞 遇到问题？

### 抓包失败
- 确保 Mac 和 iPhone 在同一个 WiFi
- 检查防火墙是否阻止了端口 8080
- iPhone 确认信任了证书

### 无法访问 mitm.it
- 确保 iPhone 已配置代理
- 尝试用 Safari 浏览器访问
- 检查代理服务器 IP 是否正确

### VPS 部署失败
- 检查防火墙是否开放了端口
- 查看日志：`sudo journalctl -u mobile-home -f`
- 确保 VPS 系统是 Ubuntu/Debian
